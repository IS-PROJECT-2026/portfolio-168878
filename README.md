## About

This site brings together my academic background, leadership experience, and core skills in one place.

**Sections:**
- **Hero / About** - introduction and quick overview
- **Projects & Experience** - leadership and experience highlights
- **Skills** - technical and soft skills
- **Contact** - ways to get in touch

## Design

- **Typography:** Cambria (serif) throughout
- **Palette:** Navy `#1F2A44` · Cream `#FBF7F2` · Blush Pink `#F0C9C9` · Lavender `#D9D3EC`
- **Navigation:** Sticky navy nav bar
- **Interactivity:** CSS-only hover transitions and hero fade-in animation

## Built With

- HTML5
- CSS3 
- GitHub Pages (deployment)

## Deployment

This site is deployed via GitHub Pages, served directly from the `main` branch at the repository root.

## Project Workflow

This project was built using a professional Git/GitHub workflow, including:
- Milestone-based planning (3 milestones, 9 issues)
- A Kanban project board (To Do → In Progress → Done)
- Feature branches following `feat/`, `fix/`, `style/`, `docs/`, `refactor/` naming conventions
- Conventional Commits
- Pull requests for every merge into `main`
- Branch protection on `main`
- Engineered and resolved merge conflicts (see `submission.md` and `/evidence` for details)
